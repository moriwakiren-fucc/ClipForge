# ClipForge

ClipForgeは、**iPadのSafariでのタッチ操作**を意識して設計した、クライアントサイド完結型の動画編集インターフェースです。動画・画像・音声をブラウザに読み込み、タイムライン上で確認、トリミング、分割、速度・色・変形・テキストを調整できます。読み込んだ素材はサーバーにアップロードせず、ブラウザのメモリ内で処理します。

| 機能 | できること |
| --- | --- |
| 素材管理 | 動画・画像・音声を複数選択して読み込み、映像・音声トラックに配置します。 |
| カット編集 | 再生、スクラブ、IN/OUT調整、プレイヘッド位置での分割、複製、削除を行えます。 |
| ビジュアル調整 | 16:9／9:16／1:1／4:5、拡大、回転、反転、色調プリセット、明るさ・コントラスト・彩度を調整できます。 |
| テキスト | 編集可能なキャプションをプレビューと書き出し映像に重ねられます。 |
| 書き出し | MediaRecorder対応ブラウザでは、選択した読み込み済み動画の最長30秒を、現在のカラ―・変形・テキスト設定で端末にダウンロードできます。 |

## iPad Safariでの使い方

Safariでサイトを開き、**「素材」または「追加」**をタップして写真ライブラリまたはファイルから素材を選択します。素材の選択後は、中央の再生ボタンと下部タイムラインで位置を決め、右側のインスペクターで調整を行います。画面の幅が狭い場合、右側のインスペクターは「調整」ボタンから開きます。

> iPadOS Safariでは、動画の再生・書き出しともユーザーが押したボタンから開始する必要があります。書き出し形式はSafariが対応するMP4またはWebMのうち、利用可能なものを自動選択します。音声ミックスや複数クリップを結合した長尺レンダリングは、ブラウザの仕様・メモリ制限を考慮して本静的版の対象外です。

## GitHub Pagesへ公開する

このプロジェクトは静的フロントエンドであり、サーバーやデータベースを必要としません。リポジトリへプッシュ後、GitHub Actionsで次の手順を実行してください。

1. GitHubの **Settings → Pages** で、公開元を **GitHub Actions** に設定します。
2. `pnpm install --frozen-lockfile` を実行します。
3. `pnpm build` で `dist/public` を生成します。
4. `dist/public` をGitHub Pagesのアーティファクトとしてデプロイします。

リポジトリ名配下で公開する場合は、ビルド時に `vite build --base=/<リポジトリ名>/` を使い、Viteのアセットパスを合わせてください。GitHub PagesではHTTPS公開にしてください。SafariのMediaRecorder、ファイルアクセス、ダウンロード機能を利用するためです。

## 既知のブラウザ上の制約

ブラウザ完結の編集は、デスクトップ編集ソフトの代替を意図したものではありません。特に大容量・長尺・4Kの動画はiPadのメモリ制限に影響されます。安定性のため、短いクリップを読み込み、書き出しは30秒以内で試してください。実際の書き出し可否とコンテナ形式は、利用中のiPadOS Safariの実装に依存します。
